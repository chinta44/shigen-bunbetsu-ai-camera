# 資源・ゴミ分別AIカメラ (shigen-bunbetsu-ai-camera)

[![Android](https://img.shields.io/badge/Platform-Android-green.svg)](https://developer.android.com/)
[![Kotlin](https://img.shields.io/badge/Kotlin-2.0+-blue.svg)](https://kotlinlang.org/)
[![Jetpack Compose](https://img.shields.io/badge/UI-Jetpack%20Compose%20M3-brightgreen.svg)](https://developer.android.com/jetpack/compose)
[![Version](https://img.shields.io/badge/Version-v1.4.3-orange.svg)](https://github.com/)

カメラで撮影した写真や商品のバーコードから、お住まいの自治体ルールに応じた正しいゴミ・資源の分別区分を瞬時に判定・案内する Android アプリケーションです。  
自治体ごとの分別基準、公式分別早見表PDFの直接照合、収集カレンダー、指定ごみ袋・粗大ごみ処理シールの実物見本写真ガイド、リサイクル回収拠点案内、GitHub Releases 自動アップデート機能を搭載しています。

## 📸 主な機能

1. **AI画像認識による高精度ゴミ分別判定（思考の連鎖 & OCR文字優先認識）**
   - 高解像度解析とChain-of-Thoughtプロンプトにより、外見シルエットだけでなくパッケージ印字（「虫さされ」「第2類医薬品」等）をOCR認識して品目を高精度特定。
   - 本体、キャップ、スポンジ塗布部、残った中身（薬品・液体）などパーツ別の分解・分別ガイドを明快に提示。
   - 自治体の分別ルールに照合して「可燃ごみ」「プラスチック類」「不燃ごみ」「粗大ごみ」「資源ごみ」「小型家電」などを瞬時に特定。

2. **自治体公式 ごみ分別早見表・ハンドブックPDFへの直接照合リンク（新機能）**
   - 判定結果画面、バーコード結果画面、収集カレンダー画面に「自治体公式 分別PDFで確認」カードを配備。
   - 自治体発行の分別早見表・ハンドブック原本（PDF）をワンタップで直接開き、AI判定の正確性を公認ガイドで確認可能。
   - 愛西市、名古屋市、横浜市、大阪市、渋谷区、札幌市、福岡市等の公式PDF・ポータルに対応し、未登録地域でも自動Web検索フォールバックを提供。

3. **GitHub Releases アプリ内自動更新システム（新機能）**
   - 新バージョン（APK）がGitHub Releasesに公開されると、アプリ起動時に検知して通知バナーでお知らせ。
   - アプリ内からワンタップで最新APKのダウンロードと更新インストールが可能。

4. **スマートフォン・小型家電の安全分別 & 拠点回収案内（火災防止）**
   - スマホ、タブレット、モバイルバッテリー、ハンディファン等のリチウムイオン電池内蔵機器や電子基板を的確に認識。
   - 収集車の火災原因となる可燃・不燃ごみへの誤分別を防ぎ、市役所・支所の「小型家電回収ボックス」やリサイクル窓口への持ち込みを明快にガイド。

5. **指定ごみ袋・粗大ごみシールの実物写真見本表示**
   - 判定結果画面に「こんな袋・シールですよ」という写真見本を自動表示。
   - 袋の色、仕様、購入先（コンビニ・スーパーなど）、出し方の注意点までわかりやすく解説。

6. **リサイクル拠点マップ検索（回収ボックス・持ち込み場所）**
   - 使用済小型家電、乾電池・充電池、蛍光管、インクカートリッジ、食品トレー、古着などの回収拠点・市役所・家電量販店をマップと一覧で確認可能。
   - 判定結果から「📍 近くの回収拠点を探す」ワンタップでスムーズにアクセス。

7. **特定被写体フォーカス解析（複数写り込み時のピンポイント指定）**
   - 机の上に複数物が写っている場合でも、「スマホ」「財布」「メガネ」など判定したい対象を入力してピンポイント解析。

8. **判定結果の手動訂正・ユーザー再分類**
   - AIの判定結果をワンタップで任意の分別区分（小型家電・不燃ごみ・粗大ごみ等）に変更・保存可能。

9. **バーコード読み取り & キーワード検索**
   - 商品のJAN/EANバーコードから分別を特定。
   - 豊富な自治体品目辞書によるリアルタイムキーワード検索。

10. **操作フィードバック設定（ポップな「ボヨ〜ン」音 & バウンス振動）**
    - 撮影時のシャッター効果音（ポップなコミックスプリング音）とバネの弾むマルチパルス触覚フィードバックを実装。
    - 設定画面でバイブレーション・効果音を個別にON/OFFカスタマイズ可能。

11. **利用者の独自 Gemini APIキー 登録機能**
    - アプリ右上の鍵アイコンから、利用者が自身で取得した無料の Gemini APIキーを簡単登録・変更可能。
    - キー未登録の場合でも、内蔵の自治体品目辞書・安全ルールベース判定が利用可能。

12. **収集カレンダー & 次回収集日カウントダウン**
    - お住まいの地区ごとの収集曜日を一覧表示。
    - 次の収集日まであと何日かを一目で把握可能。

## 🛠 技術スタック

- **言語**: Kotlin (Coroutines / Flow)
- **UIフレームワーク**: Jetpack Compose (Material Design 3)
- **アーキテクチャ**: MVVM (Model-View-ViewModel) + Repository Pattern
- **ローカルデータベース**: Room Database (履歴・設定・カスタム自治体保存)
- **AIエンジン**: Google Gemini API (gemini-2.5-flash / multimodal)
- **画像処理**: Android Bitmap / CameraX / Photo Picker
- **ネットワーク**: OkHttp / Retrofit
- **ビルドツール**: Gradle (Kotlin DSL)

## 🔑 Gemini APIキーの設定方法

1. [Google AI Studio](https://aistudio.google.com/app/apikey) にアクセスし、Googleアカウントでログインします。
2. **「Create API key」** をクリックして無料の APIキーを取得します。
3. アプリ右上の **「鍵アイコン 🔑」** をタップし、取得したキー（`AIzaSy...`）を貼り付けて「保存する」を押してください。

## 💻 ビルド & 実行方法

### 必要要件
- Android Studio Ladybug 以上
- JDK 17 以上
- Android SDK 34 / 36

### 手順
```bash
# 1. リポジトリをクローン
git clone https://github.com/<あなたのユーザー名>/shigen-bunbetsu-ai-camera.git

# 2. ディレクトリへ移動
cd shigen-bunbetsu-ai-camera

# 3. ビルド実行
gradle assembleDebug
```
